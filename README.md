# Up Studio

Site de apresentação de serviços digitais construído em React, com páginas de portfólio, serviços, sobre e contato.

## O que o projeto apresenta

- Layout compartilhado com cabeçalho e rodapé.
- Navegação por rotas e conteúdo via Outlet.
- Componentes de carrossel, feedback e chamadas para ação.

## Tecnologias

React · JavaScript · Vite · React Router · Bootstrap · Axios

## Executar localmente

```bash
git clone https://github.com/WeldonCarlos/upstudio.git
cd upstudio/up-studio
npm install
npm run dev
```

Abra o endereço informado no terminal.

## Comandos disponíveis

| Comando | Uso |
| --- | --- |
| `npm run dev` | `vite` |
| `npm run build` | `vite build` |
| `npm run preview` | `vite preview` |

Os scripts são os definidos em `up-studio/package.json`; sua presença não indica que foram executados nesta revisão de documentação.
